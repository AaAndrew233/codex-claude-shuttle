# Codex Claude Shuttle v0.1.3

This preview replaces the generic transfer icon with the mole courier mascot used on the Codex Claude Shuttle home screen. The macOS application, Windows executable, and Windows installer now share the same product identity. Conversation transfer behavior is unchanged from v0.1.2.

## What you can do

- Export active sidebar conversations from Codex or Claude Code.
- Restore native conversations to the same tool on another computer.
- Convert visible user messages and final assistant replies between Codex and Claude Code after reviewing the conversion boundary.
- Inspect, map, preflight, back up, and verify local writes before completing an import.

## Download

- `Codex-Claude-Shuttle-macOS-arm64.zip`: macOS app for Apple silicon.
- `Codex-Claude-Shuttle-Windows-x64-Setup.exe`: Windows x64 installer.
- `SHA256SUMS.txt`: cross-platform SHA-256 checksums for both packages.

## Before you install

The macOS app is self-signed and has not completed Apple notarization. The Windows installer is unsigned and has not completed physical-device acceptance testing. Both platforms may display an unknown-developer warning.

Transfer packages are local and integrity-checked, but they are not encrypted. Back up your current conversation data and test with non-critical conversations first.

# Codex Claude Shuttle v0.1.3

本预览版将通用迁移图标替换为 Codex Claude Shuttle 首页使用的小鼹鼠搬运员吉祥物。macOS 应用、Windows 可执行文件和 Windows 安装程序现在使用统一的产品形象。对话迁移功能与 v0.1.2 保持一致。

它支持从 Codex 或 Claude Code 导出真实侧边栏中的活动对话、同工具跨设备恢复，以及在确认内容边界后进行 Codex 与 Claude Code 之间的可见对话转换。

macOS 应用采用本地自签名，尚未完成 Apple 公证；Windows 安装程序尚未代码签名，也未完成实体机验收。迁移包会进行完整性校验，但当前尚未加密。首次使用前请备份现有数据，并优先用非关键对话测试。
