# Threat Model

## Protected Assets

- Codex 与 Claude Code 对话正文、内部工具输出和可能出现的源码或凭据。
- 用户现有 Codex 与 Claude Code 会话文件及其可恢复性。
- 用户文件系统边界和目标磁盘空间。
- 应用配置、日志和临时明文。

## Trust Boundaries

- 本机 Codex 与 Claude Code 数据是敏感输入，但不假定任一工具的私有格式始终正确。
- 外部迁移包是不可信输入，即使摘要校验通过。
- 前端 WebView 不可信任为文件权限边界，只能调用受限桌面 API。
- Codex 私有格式、app-server 接口与 Claude Code 经验格式都不是稳定公共契约，必须按目标工具做能力探测和格式校验。
- 同一用户权限下的其他恶意进程不在第一版可完全防御范围内，但不得主动扩大暴露面。

## Primary Threats

| Threat | Required control |
| --- | --- |
| 路径穿越、Zip Slip、符号链接逃逸 | 规范化相对路径、目标包含检查、禁止跟随链接、目标白名单 |
| 压缩炸弹或超大条目 | 条目数、元数据、单条目、总展开大小与耗时上限 |
| 清单隐藏条目 | 清单、摘要和归档清单强绑定，未声明条目拒绝导入 |
| 覆盖或破坏现有对话 | 默认跳过冲突、导入前计划、备份、恢复日志、读回校验 |
| 目标工具并发写入 | 导入前要求关闭目标工具，执行前再次检测，只阻断本次写入对应的工具 |
| 密码或明文残留 | 成熟认证加密、最短内存生命周期、受控临时目录、崩溃清理 |
| 前端越权读取文件 | 禁止任意路径 API，使用系统文件选择器与后端能力令牌 |
| 日志泄露 | 不记录正文、凭据、完整路径或迁移包内容，支持轮转与清除 |
| 远程内容利用 WebView | 不加载远程页面，限制导航，设置严格内容安全策略 |
| 完整性被误解为可信来源 | UI 明确区分“未损坏”和“来源可信” |
| Claude 私有侧边栏状态损坏或过期 | 只接受字段完整且明确未归档的元数据，并与唯一原生 JSONL 求交集；异常时不回退为全量扫描 |

## Security Acceptance

- 所有恶意迁移包测试在任何目标写入前失败。
- 取消、磁盘耗尽和进程中断后能够解释并恢复已执行步骤。
- 未加密迁移包不产生“可信发送者”提示。
- 测试、日志、崩溃报告和仓库中不出现真实会话或凭据。
